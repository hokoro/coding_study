# 코딩 테스트 기본 문법 정리

## 목차

| 분류 | 자주 쓰는 문법/함수 | 주로 쓰는 상황 |
| --- | --- | --- |
| 입출력 | `input()`, `print()`, `map()`, `split()` | 값 입력, 여러 값 입력, 결과 출력 |
| 형 변환 | `int()`, `float()`, `str()`, `list()`, `tuple()`, `set()` | 입력값 변환, 자료형 변경 |
| 리스트 | `append()`, `pop()`, `sort()`, `reverse()`, `len()`, 슬라이싱 | 값 추가/삭제, 정렬, 부분 값 가져오기 |
| 문자열 | `strip()`, `split()`, `replace()`, `find()`, `count()`, `isdigit()`, `join()` | 문자열 파싱, 공백 제거, 문자 탐색, 형 변환 검사 |
| 딕셔너리 | `dict`, `get()`, `setdefault()`, `items()`, `defaultdict` | key-value 저장, 빈도 계산, 그룹화, 그래프 |
| 집합 | `set`, `add()`, `remove()`, `discard()`, `in` | 중복 제거, 포함 여부 확인 |
| 튜플 | 튜플 생성, 언패킹 | 여러 값을 묶어서 저장, 값 분리 |
| 정렬 | `sort()`, `sorted()`, `key`, `lambda`, `reverse=True` | 단일·다중 기준 정렬, 오름차순/내림차순 정렬 |
| 반복문 | `for`, `while`, `range()`, `enumerate()` | 값 순회, 인덱스와 값 함께 사용 |
| 조건문 | `if`, `elif`, `else`, 비교 연산자, 논리 연산자 | 분기 처리, 예외 케이스 처리 |
| 기본 연산 | `+`, `-`, `*`, `/`, `//`, `%`, `**` | 사칙연산, 몫, 나머지, 거듭제곱 |
| 함수·라이브러리 | 함수 정의, `math`, `itertools`, `collections` | 재사용 코드, 순열·조합, 누적합, 큐, 빈도 계산 |
